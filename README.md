# أرشيف الوثائق — تطبيق سطح المكتب (Windows)

هذا المجلد يحوّل موقعك المنشور فعلياً إلى تطبيق ويندوز حقيقي (exe يتنصّب على الجهاز)،
بدون ما تحتاج تنصّب أي أدوات برمجة على جهازك — كل البناء يصير بالسحابة عبر GitHub.

**المبدأ:** التطبيق نافذة بسيطة تفتح موقعك (`legal-archive-beta.vercel.app`) مباشرة.
يعني أي تحديث تسويه بالموقع ينعكس بالتطبيق تلقائياً — **ما تحتاج تبني exe جديد كل مرة**،
إلا إذا غيّرت اسم التطبيق أو أيقونته أو رابط الموقع نفسه.

---

## الخطوة 1 — أضف الملفات لريبو `legal-arch`

انسخ هذا المجلد كامل (`desktop/` و `.github/workflows/build-windows.yml`) لجذر ريبو
`legal-arch` مالتك بنفس البنية بالضبط:

```
legal-arch/
├── (باقي ملفات الموقع...)
├── desktop/
│   ├── main.js
│   ├── package.json
│   └── build/
│       ├── icon.ico
│       └── icon.png
└── .github/
    └── workflows/
        └── build-windows.yml
```

**بالمتصفح:** روح الريبو → **Add file → Upload files** → اسحب المجلدين
`desktop` و `.github` مع كل محتواهن دفعة وحدة (GitHub يحافظ على بنية المجلدات
لو سحبتهن كمجلدات من جهازك). اضغط **Commit changes**.

> لو GitHub ما قبل رفع مجلدات متداخلة دفعة وحدة، ارفعهن ملف ملف عبر
> **Add file → Create new file** واكتب المسار كامل بخانة الاسم
> (مثلاً `desktop/main.js`) — هذا يخلّي GitHub ينشئ المجلد تلقائياً.

---

## الخطوة 2 — ابنِ التطبيق (زر واحد بالمتصفح)

1. روح تبويب **Actions** فوق الريبو.
2. من القائمة اليسار اختر **"بناء تطبيق ويندوز (exe)"**.
3. اضغط زر **Run workflow** (يمين) → **Run workflow** تأكيد.
4. انتظر 3-5 دقائق (تحديث الصفحة يوريك التقدّم بدائرة خضراء/صفراء).

---

## الخطوة 3 — نزّل ملف exe

بعد ما تخلص التشغيلة (✅ خضراء):

1. روح تبويب **Releases** بالريبو (بالصفحة الرئيسية، يمين تحت "About").
2. تلگى أحدث إصدار، وتحته ملفين:
   - **`...Setup.exe`** — للتنصيب العادي (اختصار بسطح المكتب + قائمة ابدأ).
   - **`...portable.exe`** — يشتغل مباشرة بدون تنصيب (يصير تشغّله من أي فلاشة USB مثلاً).
3. نزّل أيّهم تريد وشغّله.

---

## تنبيه مهم — تحذير ويندوز الأول

بما إن التطبيق مو موقّع رقمياً (التوقيع الرقمي يكلّف اشتراك سنوي ومو ضروري لأداة داخلية
لمكتبك)، أول مرة تشغّل الملف راح يطلعلك تحذير **"Windows protected your PC"** أو
**"ناشر غير معروف"**. هذا طبيعي وما يعني فيه مشكلة أمنية — بس اضغط:

**More info → Run anyway**

وبعدها التطبيق يتنصّب ويشتغل عادي كل مرة بدون تحذير.

---

## أسئلة متكررة

**سؤال: عدّلت الموقع، هل أحتاج أبني exe جديد؟**
لأ. التطبيق يفتح رابط موقعك مباشرة، فأي تحديث تنشره بـ Vercel يظهر بالتطبيق فوراً.

**سؤال: متى أحتاج أبني نسخة جديدة من exe؟**
بس لو غيّرت: اسم التطبيق، الأيقونة، أو رابط الموقع نفسه (لو غيّرت الدومين). عدّل
الملفات بمجلد `desktop/` وكرّر الخطوة 2.

**سؤال: أقدر أبني نسخة ماك أو لينكس بنفس الطريقة؟**
إي، تقدر تضيف `runs-on: macos-latest` بملف الـ workflow لنسخة ماك — گلّي إذا تحتاجها
وأجهّزها.
